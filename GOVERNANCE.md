# Project maintenance

Patina is maintained through GitHub issues and pull requests. The maintainer
sets project priorities and coordinates releases; contributors can propose
changes and discuss alternatives in the same repository.

[CONTRIBUTING.md](CONTRIBUTING.md) describes the code and content layout.
[docs/WORKFLOW.md](docs/WORKFLOW.md) lists common Git and release operations.
GitHub repository settings contain the current branch protection and access
configuration.

Labels such as `bug`, `enhancement`, `documentation`, `patterns`, `benchmark`,
`research`, `false-positive`, and `integration` help organize related work.
Issues can track a bug, question, proposal, or a larger task across PRs.
