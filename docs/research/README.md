# Research records

This directory contains dated studies, experiment designs, and implementation
notes. Sample sizes, frozen inputs, approval states, and execution orders refer
to the study that recorded them. They are historical context rather than a
repository-wide development procedure.

Current executable behavior is in `src/` and `scripts/`; test and benchmark
commands are listed in [`../QA.md`](../QA.md) and [`../HARNESS.md`](../HARNESS.md).
The records can inform new hypotheses, alternative designs, and follow-up work.
