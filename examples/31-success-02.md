# Pattern 31: 결론 신호어 남용 — Success

## Input Text

> 저녁 뒤 같은 에튀드를 40분 연습하고, 아직 미끄러지는 마디에 표시를 남겼다. 결국 이 이야기가 보여주는 것은 꾸준함의 힘이다.

## Expected Output

> 저녁 뒤 같은 에튀드를 40분 연습하고, 아직 미끄러지는 마디에 표시를 남겼다.

## Applied Pattern

- Pattern 31 (결론 신호어 남용): 본문이 이미 말한 연습 시간과 표시 행위를, 마지막 문장이 "이 이야기가 보여주는 것은"으로 교훈 이름만 붙인다. 해설을 지워도 40분, 에튀드, 미끄러지는 마디는 남는다.

## Judgment

**Success** — 교훈 문장만 지웠다. 저녁 뒤 연습, 40분, 같은 에튀드, 미끄러지는 마디에 남긴 표시는 그대로다. 연습 횟수나 다른 곡명을 보태지 않았고, 대신할 결말도 만들지 않았다.
